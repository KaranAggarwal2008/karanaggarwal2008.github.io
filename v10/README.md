# Karan Aggarwal — Portfolio V10

An editorial, eight-page personal website, produced with **HTML and CSS only**.

## Files

- `index.html` — asymmetric bento homepage and introduction
- `explore.html` — personal story, early projects, HPAIR, YCP, Model UN, Schoolhouse.world
- `build.html` — student enterprise, IDA, LaunchX, internship mentorship, Skillzo, case competitions, clubs
- `research.html` — detailed research dossiers, methods, results and publication statuses
- `recognition.html` — awards, John Locke categories and personal academic highlights
- `next.html` — future interests, education and collaboration
- `archive.html` — primary-source recordings, essays, projects, press and image-gallery links
- `cv.html` — readable, impact-oriented curriculum vitae
- `assets/style.css` — responsive design system

## How to publish

This site currently resides in the `v10/` directory on the `portfolio-v10-studio` branch to avoid altering the existing live site. You can open `v10/index.html` locally after downloading the branch. For a published site on GitHub Pages, place the *contents* of `v10/` at the publishing root of the chosen branch and select that branch/folder in Pages settings, or deploy it to another static host.

**Do not replace the current GitHub Pages homepage until the mobile layout and source links have been manually inspected.**

## Architecture and interaction

The site uses sticky navigation, HTML `details` collaborators, responsive grids, CSS hover/focus states, and print styles. No JavaScript and no build tool are required. Google Fonts are an optional remote dependency; local font fallbacks are provided. The editorial palette uses cream, forest green, sage, peach and sand.

## Source provenance and boundaries

Major first-person stories and quantitative claims are grounded in prior user interviews, original research documents, original correspondence and identified public sources. Key records include the Financial Literacy Week operations sheet, SISTER/YEL study manuscript, NSRI Finelytics draft feedback, IIM Ranchi YCP narratives, IARCO/LaunchX official recordings, and published press. The site distinguishes company offices from event roles, individual from collective achievements, articles from preprints, and conference acceptances from actual conference presentations.

**Media limitations**: Only the authenticated user's own GitHub profile image is embedded directly. Original gallery/press sources are linked rather than copying photographs without first validating identity and permissions. The user's newly uploaded ZIP archives were not programmatically unpackable in this environment. This is not a reader-facing disclosure or site placeholder.

**Publication permissions**: Some Google Drive links may need a final public-access check. Copying user private documents into a public repository is intentionally avoided. Keep private datasets, email and team rosters out of a public website.
